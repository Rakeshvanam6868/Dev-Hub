# 📬 CTA Resources

This folder contains free resources that are DM'd when someone comments the keyword on a Reel.

## Active CTAs

| Reel | Keyword | Resource | Status |
|------|---------|----------|--------|
| #2 — Don't Build Everything | `STACK` | [Mobile Dev Stack Checklist](../checklists/modern-mobile-dev-stack.md) | ✅ Active |

## How It Works

1. Viewer comments the **keyword** on the Reel
2. Instagram automation (ManyChat or similar) DMs them the link
3. Link points to the resource in this GitHub repo

## Adding a New CTA

1. Create the resource in `checklists/` or `cta-resources/`
2. Add the Reel script to `reel-scripts/`
3. Update this table
4. Update the main `README.md`
5. Set up the DM automation with the GitHub link
